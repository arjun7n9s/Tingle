# Name at launch

Working name **Tingle** until we ship. Do not block engineering on branding.

A public US storefront should talk to a trademark lawyer first. This is not
legal advice; it is the note from [decisions.md](decisions.md):

| What | Status |
|---|---|
| **TINGLE** — Tinglemore, serial 97771351, reg. 7371394 | Live. Classes 9, 38, 42. Location / social / dating software. |
| **TINGLE** — Yaniv Gershom, serial 99847921 | Pending. Class 9, humming / breathing app. |
| App Store “Tingle” | Dating apps. |

Internal / hackathon / GitHub repo can stay Tingle. A consumer-facing rename
is a **lawyer + you** decision, not an engineering one. Phase 8 does not
rename the product.
